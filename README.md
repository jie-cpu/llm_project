# llm_project

此项目用于多选题（MCQ）与简答题（SAQ）的实验与数据处理，包含主要 Notebook 与数据集文件。

## 项目结构

- `mcq+saq_llm.ipynb` — 主要 Notebook，包含数据预处理、训练与评估示例
- `dataset/` — 训练与测试数据（MCQ / SAQ）

## 使用方法

1. 在 VS Code 或 Jupyter 中打开 `mcq+saq_llm.ipynb`。
2. 按顺序运行单元格进行数据加载、训练与评估。
